# Doctor Rush: Clinic Life

Ein eigenständiger Mobile-Game-Prototyp rund um Medizin.

## Enthalten
- Hochformat-UI für Smartphone
- 8 unterschiedliche Patientenfälle
- Anamnese und Untersuchungen
- Untersuchungs-Kosten
- Diagnose- und Therapieentscheidungen
- Klinikbudget, XP, Ruf und Tage
- Schichten mit 5 zufälligen Patienten
- Klinik-Upgrades
- Autosave per LocalStorage
- PWA-Grundlage für "Zum Home-Bildschirm"

## Lokal am PC starten
Am zuverlässigsten über einen kleinen lokalen Webserver:
1. Ordner entpacken.
2. Im Ordner ein Terminal öffnen.
3. `python -m http.server 8080`
4. Browser: `http://localhost:8080`

## Auf dem Handy
Für iPhone/Android am besten den Ordner kostenlos auf GitHub Pages, Netlify, Vercel oder Cloudflare Pages hosten.
Dann die URL am Handy öffnen und zum Home-Bildschirm hinzufügen.

Hinweis: Die medizinischen Inhalte sind vereinfachtes Gameplay und keine medizinische Beratung.
